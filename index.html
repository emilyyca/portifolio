02 / PROJETOS Trabalho de Conclusão de Curso • TCC
Aplicação Web • Voleibol

Sistema de Scout Esportivo para Voleibol

Explorar projeto ↗

Aplicação web desenvolvida como Trabalho de Conclusão de Curso para registrar e analisar informações de partidas de voleibol. O projeto reúne organização de jogos, registro de ações durante a partida e apresentação de estatísticas que auxiliam a análise técnica.

Tecnologias:
  • React
  • JavaScript
  • HTML5
  • CSS3
  • Figma

Módulos integrados do sistema

01

Scout ao vivo

Registro de ações e fundamentos técnicos em quadra no decorrer da partida, permitindo anotações em tempo real com agilidade.

02

Visualização de jogos

Organização e acompanhamento estruturado dos confrontos, escalações e histórico de dados de cada partida disputada.

03

Filtros e gráficos estatísticos

Consolidação analítica de desempenho com filtros personalizados e apresentação visual de métricas para suporte à análise técnica.
