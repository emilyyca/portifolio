# Referências visuais e direção de arte

**Estilo escolhido:** minimalista editorial, como revista contemporânea / portfólio de design, sem imitar um template.

## 1. Niccolò Miranda — The Paper Portfolio
- Site: https://www.niccolomiranda.com/
- Aproveitar: títulos impactantes, hierarquia editorial, ritmo entre blocos e personalidade tipográfica.
- NÃO copiar: excesso de texturas vintage, efeito jornal antigo, cores escuras predominantes ou o desenho exato da página.

## 2. Kalok Yeung — referência no SiteInspire
- Referência: https://www.siteinspire.com/website/13158-kalok-yeung
- Aproveitar como estudo: organização do portfólio, apresentação do trabalho e equilíbrio visual entre texto e imagem.
- NÃO copiar: identidade de marca alheia, blocos idênticos, imagens ou estruturas literalmente.

## 3. Mobbin — galeria de interfaces
- Site: https://mobbin.com/
- Usar para pesquisar: padrões de navegação claros, componentes legíveis e adaptação a telas móveis.
- NÃO copiar: interface de aplicativo inteira ou padrão corporativo de cartões genéricos.
- **Antes da entrega escolar**: escolher e registrar uma tela/fluxo específico do Mobbin (com link ou captura identificável) e anotar observações reais. O endereço da página inicial, sozinho, não é uma referência específica.

## Decisão de design para o projeto
- Home: nome grande e assimétrico, microtextos laterais, navegação discreta, bordas/linhas finas; **sem foto no hero**.
- Sobre: foto real grande na vertical ao lado do texto, em uma composição editorial com etiqueta `01 / SOBRE`.
- Projeto: destaque editorial de um **único** TCC com área para capturas reais (quando fornecidas). Não fazer uma grade de três projetos fictícios.
- Contato: título expressivo, links de texto e linhas divisórias, sem formulário falso.
- Interações: hover refinado, menu funcional, revelação sutil ao rolar se não interferir com leitura.
- Paleta: off-white + grafite; lilás como detalhe, não para colorir todos os blocos.

**Nota para o documento escolar:** as descrições são intenções de referência; visite os sites e revise o que você efetivamente observou antes de entregar.
