## Projeto real — somente um projeto
**Sistema de Scout Esportivo para Voleibol**
Aplicação web desenvolvida como Trabalho de Conclusão de Curso para registrar e analisar informações de partidas de voleibol. O projeto reúne organização de jogos, registro de ações durante a partida e apresentação de estatísticas que auxiliam a análise técnica.
- Tecnologias do TCC: React, JavaScript, HTML, CSS; Figma para prototipação.
- Funcionalidades apresentáveis: scout ao vivo, visualização de jogos, filtros e gráficos estatísticos.
